2 파이프라인 상태 GitHub Actions · 로컬 빌드 · 자동 커밋
🚀 GitHub Actions — 정상
워크플로 deploy.yml · 트리거: 매일 08:00 KST + 4시간마다 + main push (data/·docs/·scripts/ 변경 시).
단계: 뉴스수집 → GS Monitor → Power BI → 인사이트 생성 → SDD → 기획전 실적 → build.py → 자동 커밋 → GitHub Pages 배포.
docs/ 만 변경 시 Python 스킵(deploy-only), push 3회 재시도 + rebase 안전망 내장.
🔁 자동 커밋 체인 — 정상
최근 자동 커밋: action calendar sync 2026-05-23 06:05.
일별 스케줄 태스크가 각자 빌드 후 git push origin main → Actions 가 Pages 재배포.
커밋 메시지에 [skip ci] 포함 시 full-build 생략, 배포만 수행.
💻 로컬 레거시 파이프라인 — 대체됨
_pipeline_status.json 의 마지막 기록은 2026-05-14 17:38 git stage 로, 로컬 run_pipeline.sh 체인은 5/14 이후 미사용.
현재 일별 데이터 갱신은 Cowork 스케줄러 + GitHub Actions 가 전담하므로 기능 공백 없음. 레거시 상태 파일은 정리 대상.
